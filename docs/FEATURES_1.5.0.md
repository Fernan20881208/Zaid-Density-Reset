# Density Reset 1.5.0 feature summary

Density Reset 1.5.0 adds four integrated capabilities without replacing the existing density/session system:

1. Game Launcher for Free Fire and Free Fire MAX with real installed app metadata, per-game last/default profile and responsive Liquid Glass UI.
2. Validated Remote Config backed by Supabase with local cache, maintenance mode, feature switches, densities, session duration and announcements.
3. Quick Settings Tile that exposes DPI/session state and delegates restoration to the existing controller/service.
4. Mandatory public GitHub Release updater with global startup enforcement, download progress, APK integrity/signature checks and standard Android installation.
