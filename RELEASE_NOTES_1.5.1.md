# Density Reset 1.5.1

- Nuevo Game Launcher para Free Fire y Free Fire MAX.
- Perfil DPI seleccionado, último perfil y perfil predeterminado independientes por juego.
- Bloqueo del DPI elegido mientras el Free Fire seleccionado permanece activo.
- Restauración automática del DPI anterior al salir del juego.
- Configuración remota mediante Supabase para mantenimiento, perfiles, densidades, anuncios y políticas de versión.
- Quick Settings Tile para restaurar el DPI o abrir el Game Launcher.
- Actualizaciones obligatorias desde GitHub Releases.
- Verificación SHA-256, package name, versionCode y certificado antes de instalar un APK.
- Startup Gate global para impedir saltarse una actualización obligatoria.
- Recuperación prioritaria de sesiones DPI incompletas antes de aplicar cualquier bloqueo.
