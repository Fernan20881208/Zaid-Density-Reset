# Density Reset 1.5.0

- Nuevo Game Launcher con detección real de Free Fire y Free Fire MAX.
- Perfil seleccionado, último perfil y perfil predeterminado independientes por juego.
- Configuración remota segura mediante Supabase para mantenimiento, disponibilidad, DPI, duración y anuncios.
- Nuevo Quick Settings Tile para abrir el launcher o restaurar el DPI rápidamente.
- Actualizaciones obligatorias desde GitHub Releases con `versionCode`, SHA-256, package y firma verificados antes de instalar.
- Startup Gate global para impedir accesos alternativos cuando existe una actualización obligatoria.
- Recuperación de una sesión DPI incompleta antes de aplicar bloqueos de actualización.
- Mejoras de compatibilidad y sincronización del estado de sesión.
